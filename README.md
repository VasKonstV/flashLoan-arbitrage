# DeFi Flash Loan Arbitrage Bot 🚀

Высокотехнологичный прототип автоматизированного торгового бота для поиска и исполнения арбитражных сделок на децентрализованных биржах (DEX) с использованием беззалогового кредитования (**Flash Loans**).

Проект разработан с акцентом на **превосходный пользовательский опыт (UX)**: транзакции подписываются и отправляются автономно на бэкенде. Для демонстрации **не требуется ручное подтверждение в MetaMask**, что обеспечивает бесшовный и плавный показ для инвесторов.

---

## 🛠️ Архитектура системы

*   **Смарт-контракты (Solidity ^0.8.20)**: Оптимизированный контракт `MyFinalLoan` для взаимодействия с протоколами флеш-кредитования и пулами ликвидности Uniswap V3 / Sushiswap.
*   **Бэкенд-сервер (Node.js / Express)**: Изолированный движок на базе `ethers.js (v6)`, отвечающий за динамический расчет лимитов газа, синхронизацию очередности транзакций (`nonce`) и прямую подпись операций приватным ключом.
*   **Интерфейс управления (UI)**: Интерактивный интерактивный терминал с живым стримингом логов работы EVM в реальном времени и наглядной визуализацией чистой прибыли в долларах (USDT).

## 💻 Инструкция по развертыванию на демо-ноутбуке

Перед запуском убедитесь, что на ноутбуке установлена среда **Node.js** (v18+) и закрыты сторонние приложения, использующие порты `8545` и `4000`.

### 1. Установка зависимостей
Откройте терминал в корне проекта и установите необходимые пакеты для бэкенда и среды Hardhat:
```bash
npm install
```

### 2. Настройка окружения (`.env`)
Создайте в корне проекта файл `.env` и добавьте туда приватный ключ кошелька-деплоера (первый приватный ключ, который выдаст локальная нода):
```text
PRIVATE_KEY=0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
```

## 🚦 Пошаговый сценарий запуска презентации

Для демонстрации необходимо открыть **3 отдельных окна терминала**. Запуск производится строго в следующем порядке:

### Шаг 1: Запуск локального блокчейна (Терминал №1)
Инициализируйте изолированную среду блокчейна со встроенным логгером EVM:
```bash
npx hardhat node
```
*Оставьте это окно открытым. Сюда будут поступать системные вызовы контрактов.*

### Шаг 2: Компиляция и деплой смарт-контрактов (Терминал №2)
Скомпилируйте Solidity-код и разверните контракты арбитража и тестовых токенов в сеть. Скрипт автоматически сохранит актуальный адрес в конфигурацию бэкенда:
```bash
npx hardhat run scripts/deploy.js --network localhost
```
*После успешного завершения это окно терминала можно закрыть.*

### Шаг 3: Запуск бэкенд-движка и UI (Терминал №3)
Запустите сервер Express на выделенном порту `4000` для управления транзакциями и раздачи интерфейса:
```bash
node server.js
```
*Консоль выведет сообщение: `🚀 Сервер запущен на http://localhost:4000`.*

## 📈 Демонстрация инвестору

1. Откройте браузер Google Chrome (или любой другой актуальный браузер) и перейдите по адресу:
   👉 **`http://localhost:4000`**
2. Сделайте жесткую перезагрузку страницы для сброса кэша: нажмите **`Ctrl + Shift + R`**.
3. Нажмите на синюю кнопку **«Запустить арбитраж»**.

### Что произойдет на экране:
*   Интерфейс мгновенно активирует встроенный дашборд `live_arbitrage_execution_stream.log`.
*   С реалистичной задержкой на экране развернется пошаговый лог: от подключения к сети и сканирования DEX-пулов ликвидности до минта тестовых токенов и совершения внутриконтрактных обменов.
*   По завершении цикла логи закроются хэшем транзакции, а система выведет финальную карточку с результатом: **💰 Прибыль: 6,000 USDT**.

## 🛡️ Безопасность и MEV-оптимизация (Ответы на вопросы инвестора)
*   **Защита от Front-running / MEV**: При деплое в Mainnet транзакции направляются через приватные RPC-узлы (например, *Flashbots Protect*), что полностью скрывает их из публичного мемпула и защищает от сэндвич-атак.
*   **Gas Optimization**: Логика контракта спроектирована с использованием низкоуровневых ассемблерных вставок (Yul) для минимизации трат на газ при межбиржевых свопах.
